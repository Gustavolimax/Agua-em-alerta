
# ÁGUA EM ALERTA
## Sistema de Detecção Preditiva de Vazamentos

### 1. Apresentação

O Água em Alerta é um projeto acadêmico desenvolvido
no curso de Análise e Desenvolvimento de Sistemas.

A proposta é desenvolver um sistema capaz de analisar
o consumo de água e identificar comportamentos anormais
que possam indicar possíveis vazamentos.

### 2. Objetivo

Contribuir para a identificação de possíveis vazamentos,
incentivando o monitoramento e o uso consciente da água.

### 3. Funcionalidades

- Registro de consumo de água.
- Organização por data e período.
- Histórico de consumo.
- Cálculo de médias.
- Comparação de consumo.
- Identificação de possíveis anormalidades.
- Emissão de alertas.
- Relatórios de consumo.

### 4. Tecnologias

- Python
- Visual Studio Code

### 5. Algoritmos utilizados

- Variáveis e tipos de dados.
- Operadores matemáticos.
- Estruturas condicionais.
- Estruturas de repetição.
- Vetores.
- Matrizes.
- Funções.
- Validação de dados.

### 6. Critérios de análise

O sistema utiliza critérios experimentais:

- Aumento superior a 30% da média: possível vazamento.
- Redução superior a 50% da média: atenção.
- Demais situações: consumo dentro do padrão.

Os critérios deverão ser avaliados e ajustados
conforme os dados reais disponíveis.

### 7. Limitações

O sistema não confirma a existência de vazamentos.
Ele identifica alterações no consumo que merecem investigação.

Os registros são mantidos em memória durante a execução.
